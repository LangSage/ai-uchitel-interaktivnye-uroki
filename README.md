# ИИ как помощник преподавателя

Интерактивная презентация для пятиминутного выступления в колледже. Внутри одного HTML-файла: 10 слайдов, четыре учебные мини-игры, заметки докладчика и плоские векторные иллюстрации.

## Как показывать

Откройте [презентацию](https://langsage.github.io/ai-uchitel-interaktivnye-uroki/) в браузере или скачайте `index.html` и откройте его без интернета.

- Стрелки влево/вправо: переключение слайдов.
- `F`: полноэкранный режим.
- `N`: заметки докладчика.
- Кнопка «Игры»: перейти к меню игр.
- `Esc`: вернуться из игры к презентации.

Игры: викторина о льде, диалог с клиентом, сортировка отходов и расследование о реке. Учебные ситуации и числа в примерах условные.
