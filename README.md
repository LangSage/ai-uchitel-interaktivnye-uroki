# ИИ как помощник преподавателя

Интерактивная презентация для выступления в колледже. Внутри одного HTML-файла: 10 слайдов, шесть разных форматов заданий, заметки докладчика и плоские векторные иллюстрации. На первом слайде есть QR-код презентации, на последнем — QR-код справочника ИИ. Девятый слайд содержит живой конструктор задания. Отдельный файл содержит только интерактивные задания. Оба файла адаптированы для телефона и поддерживают тёмную тему.

[Справочник по четырём ИИ-сервисам](https://langsage.github.io/ai-uchitel-interaktivnye-uroki/guide.html) помогает выбрать инструмент по задаче и содержит ссылки на официальные источники.

## Как показывать

Откройте [презентацию](https://langsage.github.io/ai-uchitel-interaktivnye-uroki/) в браузере или скачайте `index.html` и откройте его без интернета.

Отдельная [страница с шестью заданиями](https://langsage.github.io/ai-uchitel-interaktivnye-uroki/games.html) подходит для показа студентам. Её тоже можно скачать и открыть без интернета.

- Стрелки влево/вправо: переключение слайдов.
- `F`: полноэкранный режим.
- `N`: заметки докладчика.
- `T`: переключение светлой и тёмной темы.
- Кнопка «Игры»: перейти к меню игр.
- `Esc`: вернуться из игры к презентации.

Форматы: викторина о льде, диалог с клиентом, сортировка отходов, расследование о реке, командный раунд с таймером и баллами, интерактивная схема мотора. В командном раунде преподаватель присуждает баллы. Учебные ситуации и числа в примерах условные.
